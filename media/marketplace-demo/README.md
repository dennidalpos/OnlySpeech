# Marketplace Demo

Marketplace-ready promo assets for OnlySpeech are written here when generated.

- `onlyspeech-marketplace-demo.mp4`: silent product demo video generated from tracked repository screenshots.
- `onlyspeech-marketplace-demo-poster.png`: poster frame aligned with the demo video.

Generation uses `scripts/internal/docs/write-product-demo-video.ps1`. The current repository tree tracks this README; generated MP4/poster files should be added only when preparing marketplace video collateral.
