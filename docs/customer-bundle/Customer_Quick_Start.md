# Customer Quick Start

## Scope

This guide is the buyer-facing first-use path for the packaged OnlySpeech delivery bundle.
It assumes one Windows workstation, two active displays, and either live `kiosk` mode or deterministic `demo` mode.

## Included In The Delivered Bundle

The customer delivery generated by `npm run release:customer-bundle` contains:

- the versioned Windows installer;
- the versioned portable executable;
- the versioned unpacked archive for controlled handover or technical validation;
- this quick-start guide plus the buyer-facing legal, privacy, disclosure, and support documents.

Seller-facing marketplace copy is intentionally kept outside the buyer bundle.

## Before First Launch

Prepare the workstation with:

- Windows 10/11 x64 with built-in Windows PowerShell 5.1, `powercfg.exe`, and Windows Media Foundation components;
- two active displays for the supported operator and visitor layout;
- either two assignable microphones or one shared assignable microphone;
- the customer email and activation code delivered after purchase for that workstation;
- internet access when live `kiosk` speech is required;
- customer-owned credentials for the selected live provider: `azure` or `chatgpt`.

The setup executable checks these Windows software prerequisites before installation. If it blocks, follow the message shown by setup. On Windows N editions, install the official Microsoft Media Feature Pack and reboot before retrying.

If the workstation will be used in `demo` mode only, provider credentials and live microphones are not required for the scripted validation loop.

## First Provisioning

1. Install with the provided setup executable, or run the portable executable from the delivered package.
2. Start OnlySpeech.
3. On the first packaged launch, enter the customer email and activation code exactly as delivered after purchase.
   The packaged activation screen also offers a one-time 15-day local trial, but customer handover should use the purchased activation material.
4. If no runtime configuration exists yet, the integrated setup wizard opens automatically after activation.
5. In the Stations step, assign the operator and visitor displays, then choose the microphone profile:
   - `dual-dedicated` for one microphone per side.
   - `single-shared` for one shared microphone with alternating push-to-talk ownership.
6. In the Provider step, select `azure` or `chatgpt` for live `kiosk` speech, or switch to `demo` mode for scripted runtime validation.
7. In the Languages & Voices step, set the initial interaction languages for both sides and confirm the displayed TTS coverage state.
8. In the Diagnostics step, run provider tests or open the runtime logs folder only if the deployment needs validation or troubleshooting. Azure playback-text normalization diagnostics also require the optional Translator credentials when that specific diagnostic is used.
9. In the License step, review the installed packaged license only when you need to inspect expiry, replace the current code, or remove the stored license before a controlled reactivation. Removal now requires selecting the installed license and confirming the action from the License state panel.
10. Each setup-wizard section includes a Save action that writes the current configuration without closing the wizard.
11. In the Confirm & Save step, use `Apply and close setup` for the final save-and-close flow, then record the temporary setup-wizard password if the app shows one for later authenticated re-entry.

## Daily Use

- Launch the packaged application normally from the installed shortcut or executable.
- Use the same purchased customer email and activation code again only if the workstation profile is removed, the app is reinstalled without preserved local data, or support instructs you to reactivate the workstation.
- Use the configured operator display and visitor display on the same workstation.
- Keep conversation history disabled unless the local deployment explicitly requires it.
- Reopen the setup wizard only when displays, microphones, provider credentials, initial language defaults, or the packaged license state need to change.
